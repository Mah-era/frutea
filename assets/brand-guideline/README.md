# FruTea Brand Guideline

This folder contains the working brand guideline kit for FruTea Instant.

FruTea Instant is an instant fruit-flavoured tea powder brand for Bangladesh. The brand should feel fresh, energetic, colourful, youth-friendly, affordable, and easy to understand at a glance.

## Files

- `brand-system.md` - brand positioning, voice, colour, typography, logo, and layout rules.
- `packaging-guideline.md` - rules for sachets, the Mix Pack, planned Low Sugar packs, and serving glass visuals.
- `motion-3d-guideline.md` - website animation, scroll, glass, ice, product render, and always-on 3D rules.
- `asset-index.md` - where to find usable logos, mascots, product renders, videos, and 3D files.
- `design-tokens.json` - reusable brand colours, typography, flavour names, product data, and motion values.
- `brand-tokens.css` - CSS custom properties for frontend implementation.

## Core Direction

Keep FruTea product-led. The pack, glass, fruit elements, ice, straw, and mascot should do the visual work. Backgrounds can be bright, but they should not fight the drink colour or hide the product.

Use the current product data in `../../product.md` as the source of truth.
